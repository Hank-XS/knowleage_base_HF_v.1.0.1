9. 依赖、假设与风险

9.1 依赖与假设

  1. M0 不依赖客户真实代码；CardDemo + ATM/hf_data 即可。
  2. 行内 GPU/模型未就绪时，W1–W4 可用 Mock/兼容接口；W5 必须完成行内模型对比。
  3. W7 前客户确认试点子系统，并提供 ≥2 名审核专家窗口。
  4. Neo4j Enterprise 未采购时，按设计 §6 启用 Community / PG+AGE 等退化方案，不阻 Demo/M1。

9.2 风险（对齐设计 §12）

风险 应对 缓冲
Demo 范围蔓延 严格 §4.4；争议当日 PM 裁决 W1–W2 每日站会
模型 COBOL 弱 任务切小 + 强制注入结构事实 W5 多模型并行
动态调用遗漏 常量传播 + 未解析强制曝光 W3 关闭项
专家排期不足 只审中心度 Top-N W9–W10
图性能不足 模板限跳数；物化热点路径 W6/W14

W6、W10、W14 各预留 2–3 人日缺陷缓冲。
