# ATM 取款业务流程规范 V3.2

## 1. 交易概述

ATM 取款是客户通过 ATM 渠道发起的自助取款交易，主流程为：插卡验密 → 金额输入 → 余额校验 → 限额校验 → 出钞控制 → 主机记账 → 返回回执。核心账务系统通过 CICS 交易 ATMWD402 处理该业务。

## 2. 余额校验流程（6.1）

余额校验在扣款前执行，由程序段 4020-CHECK-BAL 完成。校验规则：可用余额（AVAIL-BAL）须大于等于取款金额（TRAN-AMT）。可用余额 = 账户余额 - 冻结额度 - 未清算在途金额。

境外卡（外卡）取款时，需先将取款金额按当日牌价转换为主机记账币种，再与可用余额比较；币种转换精度导致的差额由手续费科目吸收。

校验不通过时返回错误码 14（账户可用余额不足）；冻结/止付卡返回错误码 21。

## 3. 限额校验（6.2）

单卡单日取款累计不超过等值 2 万元人民币，由程序段 4030-CHECK-LIMIT 实现。境外卡受跨境取款限额约束（等值 1 万元人民币/日）。超限返回错误码 15。

## 4. 出钞控制（6.3）

出钞控制段 4040-DISPENSE-CASH 与设备侧交互：核对钞箱余量（不足返回错误码 61），执行出钞动作，确认出钞结果。出钞失败但已记账的，触发冲正流程 CORRECT-402。

## 5. 记账与回执（6.4）

记账段 4050-POST-ENTRY 写入存款模块账务表 DEPOSIT-LEDGER，并更新账户余额。主机交易超时（错误码 32）时，以 TXN-SEQ 幂等查询最终状态，避免重复记账。

回执报文 atm_withdraw_response 返回响应码、交易后余额、可用余额、币种与流水号，字段映射见 mapping_atm_withdraw（目标系统为 NEW 新核心，迁移后沿用该映射）。

## 6. 历史缺陷记录

2022 年利率调整缺陷（工单 T-2022-0611）：INT-CALC 程序利率精度处理错误导致利息计提偏差，修复后新增四舍五入规则。2023 年外卡币种转换缺陷（工单 T-2023-0225）：AVAIL-BAL 比较时未先行币种转换，导致外卡取款误报错误码 14，已在 4020-CHECK-BAL 段增加前置转换。
