# ATM 余额查询业务说明

## 1. 功能说明

ATM 余额查询为客户提供账户可用余额与冻结金额的查询服务，不发生资金变动。CICS 交易入口为 ATMBAQ101。

## 2. 处理流程

查询流程：插卡验密 → 账户定位 → 余额读取 → 组包返回。可用余额口径与取款交易一致（账户余额 - 冻结额度 - 未清算在途金额），确保查询展示余额与取款校验结果一致。

外卡查询时，返回余额按查询时点牌价转换为客户卡面币种展示，仅作展示用途，不改变记账币种。

## 3. 卡种口径说明

系统内卡种存在两种口径并存：三种口径（借记卡、贷记卡、准贷记卡）为账务口径；六种口径（Smart卡、HBC卡、借记卡、贷记卡、准贷记卡、预付卡）为渠道口径。Smart 卡在账务口径归入借记卡，HBC 卡归入贷记卡。接口字段 CARD-TYPE 使用三种口径编码，迁移到新核心 PAY_CARD_KIND 时按六种口径展开。
